# Pac-Man em Pygame

Versão simplificada do Pac-Man criada em Python e Pygame, como mostrado no
vídeo. Percorra o labirinto, coma as bolinhas e fuja dos dois fantasmas que
perseguem o jogador.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python pacman.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use as **setas** para mudar a direção do Pac-Man. Feche a janela para sair.

## Código passo a passo

O arquivo `pacman.py` contém o jogo completo. A pasta `passos/` mostra as
quatro versões executáveis apresentadas no vídeo: labirinto, Pac-Man,
primeiro fantasma e fantasma rosa.
